# 私域视频课微信小程序系统

本仓库提供一套「微信小程序前端 + Node.js(Express) 后端 + 简易 Web 管理后台」的示例工程，用于售卖私域视频课程（已内置示例课程「私域操盘课」）。结构清晰，方便后续扩展多课程、多讲师与运营玩法。

## 1. 这套系统包含什么（老板/运营能看懂的版本）
1. **微信小程序学员端（/miniapp）**：学员浏览课程、试看/购买、播放小节、查看订单与学习进度。
2. **Node.js + MySQL 后端（/server）**：课程/模块/小节数据管理、下单和支付回调（支付流程用伪代码示意）、用户权限校验、学习进度记录。
3. **简易 Web 管理后台（/admin）**：老板/运营可登录后创建/编辑课程、维护模块和小节、查看订单和基础统计，并配置社群入口文案。

## 2. 本地从 0 跑通步骤清单
1. **准备环境**：安装 Node.js (>=18)、MySQL (>=8.0)、微信开发者工具；克隆仓库。 
2. **初始化数据库**：创建数据库 `private_courses`，执行 `server/db/schema.sql` 导入表结构与示例数据。
3. **配置环境变量**：复制 `server/.env.example` 为 `.env`，填入数据库、微信、小程序、支付、管理员账号等占位值。
4. **启动后端**：
   ```bash
   cd server
   npm install
   npm run dev
   ```
5. **启动管理后台**：
   ```bash
   cd ../admin
   npm install
   npm run dev
   ```
   默认调用同一台本地后端（可通过 `ADMIN_API_BASE` 定向）。
6. **导入微信小程序**：在微信开发者工具中选择 `/miniapp` 目录，填入自己的 APPID，设置 `app.js` 中 `baseURL` 指向后端地址（本地示例为 `http://localhost:3001`）。
7. **演示流程**：
   - 打开小程序 → 进入「私域操盘课」详情 → 下单（使用内置伪支付流程自动回调）→ 订单变为已支付 → 已购状态解锁全部小节 → 在播放页记录学习进度。

## 3. 环境与配置
- **需要安装的软件**：
  - Node.js >= 18
  - MySQL >= 8.0
  - 微信开发者工具（用于导入 `/miniapp`）
- **数据库初始化**：
  - 创建数据库：`CREATE DATABASE private_courses;`
  - 执行 `server/db/schema.sql` 导入表结构与示例课程/讲师/小节数据。
- **环境变量（.env）**：
  - `DB_HOST`、`DB_USER`、`DB_PASSWORD`、`DB_NAME`
  - `JWT_SECRET`（登录 token）
  - `WECHAT_APPID`、`WECHAT_APPSECRET`
  - `WECHAT_MCHID`、`WECHAT_PAY_KEY`、`WECHAT_NOTIFY_URL`（支付回调地址）
  - `ADMIN_USERNAME`、`ADMIN_PASSWORD`（管理后台登录账号，可用示例 admin/admin123）
  - `CORS_ORIGIN`（小程序/后台允许的域名）
- **微信后台需配置的域名（TODO 需运营在微信平台手动配置）**：
  - request 合法域名：后端 API 地址
  - uploadFile/downloadFile 合法域名：视频/素材存储域名
  - 业务域名：后端业务域名
  - 支付回调地址：`WECHAT_NOTIFY_URL` 对应的公网地址

## 4. 目录结构速览
- `/miniapp`：原生微信小程序代码（课程列表、详情、播放、订单、我的）
- `/server`：Express + MySQL 后端，包含接口路由、权限校验、中间件、SQL 脚本
- `/admin`：基于 Express + EJS 的简易管理后台（登录、课程/模块/小节维护、订单查看）
- `/docs`：可放置额外文档

## 5. 谁来做什么？
- **需要程序员完成**：
  - 部署服务器、Nginx/HTTPS、配置真实域名；
  - 真正接通微信登录/支付（替换伪代码、补充签名校验）；
  - 视频防盗链/加密、更多安全策略；
  - 生产级日志、监控与告警。
- **运营/老板可以独立完成**：
  - 在后台创建/编辑课程、上传封面与视频链接、撰写文案；
  - 调整价格、上架/推荐设置；
  - 配置社群二维码和说明文案。

## 6. 安全与防盗版提示
- 视频地址建议部署到支持防盗链的点播服务，这里仅预留 `video_url` 字段。
- 非试看内容均需登录+已购校验后端接口，前端只做展示控制。
- 微信支付回调的签名校验在示例中简化，生产环境务必按官方文档实现，并开启 IP 白名单、重放保护等机制。
- 建议结合 CDN、鉴权签名、限流和审计日志等进一步加固。

## 7. 技术栈说明
- 后端：Node.js + Express + MySQL，轻量易扩展。
- 管理后台：Express + EJS 模板，便于快速迭代（后续可替换为 React/Ant Design 等）。
- 小程序：原生 WXML/WXSS/JS，封装统一请求与登录。
